# Общий рейтинг — сервер в Yandex Cloud

Облачная функция принимает рекорды из трёх игр и отдаёт таблицы «за всё время» и «эта неделя» (неделя — с понедельника 00:00 по Москве). Данные лежат в Object Storage, по одному JSON на игру (`rating/chips.json`, `rating/toly.json`, `rating/trap.json`). Игрока функция узнаёт по подписи Telegram (`initData`), поэтому чужое имя подставить нельзя.

Файлы: `core.js` — вся логика, `index.js` — обёртка для Yandex Cloud, `package.json` — зависимости (Yandex Cloud установит их сам).

## Настройка (один раз, ~20 минут)

1. **Аккаунт.** Зайди на [console.yandex.cloud](https://console.yandex.cloud), создай платёжный аккаунт (нужна карта; при таком трафике всё укладывается в бесплатный лимит). Создастся облако и каталог `default`.

2. **Бакет.** «Object Storage» → «Создать бакет»:
   - имя, например `chipsy-rating` (должно быть уникальным во всём Yandex Cloud);
   - доступ на чтение и к списку объектов — **ограниченный** (публичный не нужен);
   - класс хранилища — стандартный, максимальный размер — 1 ГБ.

3. **Сервисный аккаунт.** «Identity and Access Management» → «Сервисные аккаунты» → «Создать»:
   - имя `chipsy-rating`, роль `storage.editor`;
   - открой его → «Создать новый ключ» → «Статический ключ доступа». Сохрани **идентификатор ключа** и **секретный ключ** — секрет показывают один раз.

4. **Функция.** «Cloud Functions» → «Создать функцию» → имя `chipsy-rating`:
   - среда выполнения **Node.js 18** (или новее);
   - способ — «ZIP-архив», загрузи `rating-function.zip` (собирается командой ниже);
   - точка входа: `index.handler`;
   - таймаут 10 с, память 128 МБ;
   - переменные окружения:
     - `BOT_TOKEN` — токен бота от @BotFather (тот же бот, в котором открывается игра);
     - `BUCKET` — имя бакета из шага 2;
     - `AWS_ACCESS_KEY_ID` — идентификатор статического ключа;
     - `AWS_SECRET_ACCESS_KEY` — секретный ключ.
   - «Сохранить изменения».

5. **Сделать публичной.** На странице функции включи «Публичная функция». Скопируй ссылку вида `https://functions.yandexcloud.net/d4e…`.

6. **Подключить к игре.** В `js/rating.js` впиши ссылку в `cfg`: `url: 'https://functions.yandexcloud.net/d4e…'`, подними версию `?v=` в `index.html`, закоммить и запушь.

Токен бота и ключи хранятся только в переменных функции — в репозиторий их **не** коммитить.

## Собрать архив

```bash
cd server/rating && zip -r ../rating-function.zip core.js index.js package.json
```

## Проверка

В Telegram открой игру → «🏆 РЕЙТИНГ». Сыграй забег — результат появится в обеих колонках. Старые рекорды из телефона один раз уходят только в «за всё время».

Если таблица не грузится: страница функции → «Логи».
